# MyFlix Project 🎬

This is a Netflix UI clone created for **educational purposes only**.  
It is not affiliated with Netflix in any way.

## 🚀 Features
- Movie browsing layout
- Responsive design
- Demo UI (no real login or streaming)

## 📦 Deployment to GitHub Pages
- Run `npm run build` to generate `dist/`.
- Run `npm run deploy` to push to `gh-pages` branch.
- Site: https://<your-username>.github.io/evangadi_project

## ⚠️ Disclaimer
This project is a **practice clone** and does not collect any personal data.  
Logos and branding have been replaced with original placeholders.

## 🔧 Local Setup
- `npm install`
- `npm run dev`
- For API: Use mock data or a secure proxy (no client-side keys).
